Before you connect

Your ReadyKin account stays in control.

  • Review requested permissions before connecting.
  • Changes use a prepare, review and apply flow.
  • Disconnect an assistant whenever you want.

Choose your assistant

Setup instructions

Use the same server URL everywhere. Clients that support OAuth discovery register themselves automatically, so you do not need to create or paste a secret.

C

ChatGPT

In ChatGPT, open Settings → Apps & Connectors → Advanced settings → Developer mode. Add a custom connector named ReadyKin, paste the server URL, turn on Requires sign-in, and leave Client ID and Client secret blank.

C

Claude

Open Customize → Connectors → Add → Custom → Web. Name it ReadyKin, paste the server URL, choose Sign in now, then use Claude’s published identity or automatic registration. No client secret is needed.

C

Claude Code

Run claude mcp add --transport http readykin https://mcp.beforeleaving.app/mcp. In Claude Code, run /mcp, select ReadyKin and complete sign-in in your browser.

C

Cursor

Open Cursor Settings → Tools & MCP → New MCP Server. Add the JSON below to ~/.cursor/mcp.json, return to MCP settings and choose Connect when ReadyKin asks you to sign in.

G

Google Antigravity

Open the Agent panel menu → MCP Servers → Manage MCP Servers → View raw config. Add the JSON below to ~/.gemini/config/mcp_config.json, then authenticate ReadyKin in Agent Settings → Customizations.

G

Gemini CLI

Add the JSON below to ~/.gemini/settings.json. Start Gemini CLI, run /mcp auth readykin, and finish the browser sign-in.

O

OpenCode

Run opencode mcp add readykin --url https://mcp.beforeleaving.app/mcp, then opencode mcp auth readykin. OpenCode discovers OAuth and registers automatically.

Connection help

Do I need a client ID or secret?

No. Leave those fields blank unless your client specifically requires them. ReadyKin supports secure automatic client registration for public MCP clients.

How do I use ReadyKin in a chat?

Turn on ReadyKin from the chat’s tools or connectors menu, then ask naturally. The assistant may request approval before calling a tool or saving a change.

What if sign-in does not open?

Confirm that the server address is exactly https://mcp.beforeleaving.app/mcp, reload the client’s MCP connections, and choose Authenticate or Connect again. Command-line clients need access to a local browser callback.

Can I remove access later?

Yes. Disconnect ReadyKin in the AI client and revoke the connection from ReadyKin’s connection-management page.
